Features

Local PDF Viewer

Open and render PDFs natively inside Electron with optimized memory management. No cloud upload, no external viewer needed.

Toggle distraction-free layout — hides all non-essential UI elements, leaving only your content.

Questions

Frequently asked questions

Is Studium a replacement for Chrome/Edge?

No. Studium is a focused tool for PDF-heavy study sessions. It lacks extensions, sync, dev tools, and many web platform features. Use it alongside your main browser.

Why is there a 5-tab limit?

The hard cap prevents accidental RAM overload and encourages intentional browsing. You can discard inactive tabs to make room. This is a feature, not a bug.

Does it work on macOS or Linux?

Currently Windows 10/11 only. The Electron build targets Windows (NSIS installer). macOS/Linux builds are on the roadmap but not yet released.

Is my data sent anywhere?

No. Studium has zero telemetry, no analytics, no auto-updates that phone home, and no account system. It runs entirely locally.

Can I customize the tab limit?

Not in v1.x — the 5-tab limit is hardcoded to enforce the design philosophy. Future versions may offer a "power user" override with warnings.

What PDF features are supported?

Zoom, rotation, thumbnail navigation, page jump, text selection, search within PDF, and keyboard navigation. Annotations and forms are not yet supported.
